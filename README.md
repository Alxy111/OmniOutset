# 🚀 Initial Release (v1.0.0)

Welcome to the first official release of **OmniOutset**! 

This initial version is designed to bring industry-standard, truly equidistant outsets right into your Blender modeling workflow, saving you from messy overlaps and manual tweaking.

### ✨ Initial Features Included:
* **True Equidistant Edge Extrude:** Added a new tool to create flawless, uniform thickness along any complex boundary.
* **Smart Face Extrude:** Added a smart face extrusion tool that perfectly achieves equidistant offsets while extruding along the normal. It includes automatic capping for open sheets and clean internal topology maintenance for solid meshes.
* **Context Menu Integration:** Seamlessly integrated into Blender's Edit Mode. Simply select your geometry, Right-Click, and find the new tools under the "OmniOutset Tools" menu.

### 💻 Compatibility
* Fully compatible and optimized for Blender 4.2 and above.

Thank you for trying out OmniOutset! If you encounter any bugs or have feature requests, please let us know on our GitHub Issues page.
